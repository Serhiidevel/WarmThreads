# WarmThreads

Front-end clothing store project built to practice **JavaScript DOM manipulation**, responsive layout, and UI interactions (burger menu, cart modal, add-to-cart animations).

## Demo
- **Live preview**: (add your deployed link here, e.g. GitHub Pages / Vercel / Netlify)
- **Repository**: https://github.com/Serhiidevel

## Features
- Responsive burger navigation (mobile/tablet)
- Product slider (Swiper)
- Cart modal (open/close, add/remove items)
- Cart indicators:
  - Desktop: badge with item count
  - Mobile: red dot in burger menu when cart has items

## Tech stack
- HTML5
- JavaScript (vanilla)
- Sass/SCSS
- Vite
- Swiper

## Getting started
### Requirements
- Node.js (LTS recommended)

### Install & run (recommended)
```bash
npm install
npm run dev
```
Then open the local URL shown in the terminal.

### Build for production
```bash
npm run build
npm run preview
```
